# 逐模块授课讲稿审核清单

## 必须通过（硬规则）

- [ ] 当前上传源文件实际有 N 页，MD 正好有 N 个 `## Slide NN`，编号连续不重复。
- [ ] 每页有对应的 `slide_images/slide_NN.png` 真实文件，ZIP 内相对路径一致。
- [ ] 每页至少一个 `### Module NN`；每个模块都有 A 原文、B 可朗读英文、C 中文提示。
- [ ] 全页**不存在单独把全部原文堆在前面**再一次性讲解的情况。
- [ ] 原文经过换行清理，但未变更数值、词汇、引用、公式、代码和真实表格单元格。
- [ ] 该模块中的图中文字已目视核对；无法辨认的内容清楚标注。
- [ ] 模块分区与页面视觉布局一致；没有 A 归属左栏，B 却讲右栏的现象。
- [ ] B 不混入中文可朗读句；C 的中文指图提示清楚、具体。
- [ ] `Transition to Next Slide` 位于当前页**所有模块之后**；最后一页不错误预告下一页。

## 质量抽查（每页人工检查）

1. **原句重用**：抽取 B 中 3–5 个核心句，与 A 或图中文字核对。原句自然时是否直接复用？
2. **讲解覆盖**：当前模块的重要要点、案例、数值、表格维度、箭头步骤有无漏掉？
3. **模块内闭环**：是否连续讲完整个模块才进入下一模块？有没有 `as you can see on the right` 提前跳讲？
4. **英文难度**：简单、短句、好读；技术术语准确、句子完整。
5. **拒绝套话**：是否有大量反复的“Here, the key point is”或与原页面无关的自创过渡？
6. **事实忠实**：未悄悄修改源文件表达；任何外部核查已单独标识。

## 三组示范性抽查页

- 三栏对比页：**完整左栏→完整中栏→完整右栏→底部结论**。
- 复杂时间线：源时间轴的年/月、节点、箭头顺序讲完，不跳过核心转折。
- 图文结合页：一张图相关的可见说明和图中文字在**同一个模块**；A/B/C 彼此贴近。

## 技术检测脚本的能力边界

`scripts/validate_output.py` 仅能检查页码、模块 A/B/C、占位符、截图引用及路径，对“原文是否逐字正确”和“讲稿是否按图片顺序”**必须逐页视觉检查**。
